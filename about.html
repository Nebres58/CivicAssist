About CivicAssist

A student demonstration of a community services information portal.

Student demonstration project. CivicAssist is not an official government website and is not affiliated with any agency.

What it is

A responsive community information portal covering services, announcements and emergency contact formats.

Problem it addresses

Community information is often scattered. CivicAssist shows how it could be organized in one searchable place.

Who can use it

Anyone exploring the demo, especially residents, students and evaluators.

Main features

Search and filter

Find services fast by keyword or category.

Clear requirements

Step-by-step preparation for each service.

Announcements

News with dates and expiry status.

Favorites

Save services in your own browser.

Technology and no database

Built with HTML5, CSS3 and vanilla JavaScript only. Content is read from static JSON files, so no backend or database is needed and it runs on GitHub Pages.

Limits of local storage

Favorites live only in this browser on this device. Clearing site data, using private mode or switching browsers removes or hides them.

Why verify information

All records are fictional examples. Requirements, fees, hours and phone numbers must be verified with real local offices.
